# Rolling Wavy Pen storyboard study v3

Status: visual review pending. This revision strengthens centerline curvature over the entire 141.8 mm pen, including the cap, cap step, shaft, and tip. The straight pose remains unchanged. Curved uses one full-length bow; Wavy uses smooth repeated bends; Highly Wavy uses unequal amplitudes and spacing.

Four printable representative poses are in `exports/rolling-wavy-pen/storyboard-study-v3/`. Their Blender scene is `models/rolling-wavy-pen-storyboard-study-v3.blend`. Contact sheets, cap close-ups, and the four-stage GIF are under `previews/rolling-wavy-pen/storyboard-study-v3/`. Regenerate with Blender 4.5 LTS using `blender --background --python scripts/rolling_wavy_pen_storyboard_study_v3.py`.

The validation record includes STL dimensions, topology, normals, degenerates, detected non-adjacent overlaps, tabletop contact, and support margin. Independent STL regeneration matched all four file hashes. Minimum wall thickness, slicer behavior, and physical printing remain unverified.
