## 依存関係と文書の変更

Cube v4は旧v3シーンと43 STLへの依存を除去し、承認済み12 STL、manifest、最終シーンを固定入力にして再構成する。
出力先は別ルートの指定を必須にした。

Wavy v11は旧v8の定数を取り込み、中心線と形状計算を変更せず独立させた。

WavyのQAでは、生成器ファイルのバイト一致を形状同一性の判定から分けた。
承認済みBlendとSTLのハッシュ一致、選定全形状の独立再生成メッシュ指紋一致は引き続き必須とする。
既存の最終QAは検証当時の記録として変更せず、そこにある生成器の旧ハッシュは履歴情報として扱う。

制作判断は`specification.md`、`stone-to-bread.md`、各最終印刷ガイドへ統合した。
旧版専用の報告書と`previews/README.md`は削除し、READMEを作品一覧と正式成果物への入口に絞った。
巨大な棚卸し一覧は削除記録だけへ置き換えた。

- 正式STL75件は既存QAのSHA-256と一致。3MF3件、保持するBlend、GIF、構成PNG、撮影データも整理前と一致した。
- Cube v4を一時ルートへ再構成し、12 STLのバイト一致、61ポーズの配置一致、20物体、74露光、分離後の静的支持を確認。保存し直した一時シーンのQAはPASS。
- Wavyの全30生成形状は変更前の座標と面構成に一致し、面方向を正規化した保存メッシュ指紋も一致。旧v8を含まない一時入力セットで16 STLの最終QAはPASS。

- Cube v2の形状と運動を計算する関数は、旧比較処理を除いて構文木が変更前と一致。
- READMEと残存文書の相対リンクを検査し、リンク切れなし。Pythonの構文解析も成功。

全レンダーと全作品のゼロからの再生成は実施していない。
Git LFSのローカル実体は保持したが、今回リモートからの再取得は検証していない。
